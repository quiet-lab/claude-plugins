# Плагин ask-gate

Ворота вопросов пользователю: вопрос задаётся через `AskUserQuestion`
с вариантами, а не прозой в конце хода.

## Поведение

Хук `hooks/ask-gate.py` на событии `Stop` возвращает агенту ход, если конец
хода содержит вопрос пользователю в прозе. Вывод — `{"decision": "block", "reason": "…"}`, код всегда 0.

Хук пропускает ход без проверки:

- `stop_hook_active` — один отказ на ход, без петли;
- `DUTY_ROLE=worker` — агент задачи плагина duty спрашивает файлом `ask.py`;
- `CLAUDE_CODE_ENTRYPOINT`, начинающийся с `sdk` (`claude -p` даёт `sdk-cli`,
  SDK — `sdk-py`, `sdk-ts`): пользователя и карточки нет, возврат хода
  подменил бы итоговый ответ вторым и потратил запрос;
- любой сбой чтения входа или транскрипта: хук не мешает завершению хода.

## Источники

Текст конца хода — поле `last_assistant_message` входа хука: на момент `Stop`
последнее сообщение агента в транскрипт ещё не записано. Без поля — последний
текстовый блок транскрипта, если после него агент не вызывал инструментов.

Границы хода — транскрипт JSONL: ход начинается с последнего сообщения пользователя.
Сообщение пользователя — запись `type: "user"` со строковым `content` или
блоками `text`; не считаются записи `tool_result`, записи субагентов
(`isSidechain`), сводки компакции и служебные `isMeta` без `origin` и
`turnPosition` (тело навыка, замечание хука). Сообщение другой сессии (`isMeta` с `origin`) начинает новый ход.

## Что считается вопросом

Абзац — блок до пустой строки; пункт списка — свой абзац. Вопрос — абзац, который:

- заканчивается знаком `?` (допускаются `!` и закрывающая разметка за ним);
- или является последним абзацем хода и содержит предложение со знаком `?`
  (за вопросом идёт текст: «Сливать? Рекомендую да.»); знак `?` внутри слова
  или адреса (`a?b=1`) не считается;
- или содержит оборот «что думаете», «как поступить», «или …?»;
- или содержит оборот «подтвердите» либо «оставить как есть» и знак `?`
  в том же абзаце: «Подтвердите: сливать?» — вопрос, «Подтвердите вход
  в окне sudo.» и «Решено оставить как есть.» — нет.

Не считаются заголовки Markdown (`#`), строки цитат (`>`), строки таблиц (`|`), блоки кода (```` ``` ````,
`~~~`) и код в строке (`` `…` ``).

## Исключение по пометке

Блок или пункт списка, начинающийся с «Риторически:» или «Вопрос не к вам», не
считается; пометка в начале блока действует и на его пункты. Так пересказываются чужие вопросы, например вопросы
субагента в отчёте:

```text
Вопрос не к вам: субагент спрашивает, сливать ли ветвь?
```

Пометка действует до пустой строки: вопрос пользователю следующим абзацем
возвращает ход.

## Ограничения

- `AskUserQuestion` проверку не снимает: проза с вопросом после карточки,
  успешной или с ошибкой схемы, возвращает ход как без вызова.
- Оборот «что думаете», «как поступить» или «или …?» в пересказе возвращает
  ход один раз; такой абзац помечается «Вопрос не к вам».
- Вопрос в кавычках или скобках внутри последнего абзаца считается вопросом.

## Установка

```sh
claude plugin marketplace add quiet-lab/claude-plugins
claude plugin install ask-gate@quiet-lab
```

## Проверка

```sh
python3 -I -m unittest discover -s plugins/ask-gate/hooks/tests
printf '{"transcript_path":"<путь к транскрипту>","stop_hook_active":false,"last_assistant_message":"Сливать ветвь?"}' \
  | env -u DUTY_ROLE -u CLAUDE_CODE_ENTRYPOINT python3 -I plugins/ask-gate/hooks/ask-gate.py
```

Второй запуск печатает решение `block`.
